# Hotkeys

| Key    | Action              |
|--------|---------------------|
| INSERT | Toggle overlay      |
| F1     | Toggle ESP          |
| F2     | Toggle Godmode      |
| F3     | Toggle Aimbot       |
| F4     | Cycle target build  |

Hotkeys are read from `config/hotkeys.json` on startup. Restart the trainer after editing.
